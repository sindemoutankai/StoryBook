# 翻訳ルール（現実の悩み→動物ファンタジー）
- 主人公は動物にする
- 現実の肩書、職場、家庭事情などは直接書かず、森、空、海、群れ、巣、旅などの世界に置き換える
- 悩みの核だけを取り出し、子どもにもわかる困りごとに変換する
- たとえば「経験不足」「役割不安」「比較」「自信のなさ」は、飛べない、泳ぎが遅い、道を覚えられない、群れに合わせるのが苦手、などに変換してよい
- 主人公には、ずっと気にしている「苦手さ」や「足りなさ」を持たせる
- その苦手さは、最後に見方が変わり、主人公ならではの役割や強みだったとわかるようにする
- 問題を無理に敵キャラ化しなくてよい。必要なら風、霧、重たい石、遠い空など、やわらかい象徴表現にしてよい
- 会話ログの具体的な専門用語や制度名はそのまま出さない

# 物語構成ルール
- 全10ページ構成にする
- 物語は「説明」ではなく「情景と会話」で見せる
- 後半には、主人公と似た悩みを持つ年下や仲間を登場させる
- 主人公は、以前にもらった言葉や気づきを、その相手にやさしく渡す
- その場面を通して、主人公自身も「自分の弱さは、別の形では大事な力だった」と気づく
- 最後は誰かに結論を言われて終わるのではなく、主人公の静かな気づきと、明るい未来の情景で終える

# 10ページの流れ
p1: 主人公紹介と、抱えている悩み
p2: まわりと比べて苦しくなる場面
p3: 悩みが深まり、自分は役に立てているのか不安になる
p4: 主人公が信頼できる相手に気持ちを打ち明ける
p5: その相手が、主人公の悩みを受け止める
p6: 別の見方や、弱さの中にある価値がそっと示される
p7: 後半で、主人公と似た悩みを持つ年下や仲間が現れる
p8: 主人公がその相手に言葉をかける
p9: 主人公が、自分の役割や強みに気づく
p10: 安心と希望のある結末。これからも大丈夫そうと感じられる未来描写

# 文体ルール
- 絵本らしく、やさしく、短い文で書く
- 子どもにも読めるように、むずかしい言葉は避ける
- ひらがなを多めにしてもよい
- 一文は長すぎない
- 抽象的な説明より、気持ちが伝わる場面を優先する
- 読み聞かせしやすい自然なリズムにする

# 避けること
- 悩みをそのまま説明すること
- 主人公を一気に成長させすぎること
- 説教っぽいまとめ
- 露骨な教訓
- 現実の制度・肩書・会社・育休・産休などを直接書くこと
- 無理に敵や悪役を強く出すこと
- 過度に劇的な対決や暴力的表現
